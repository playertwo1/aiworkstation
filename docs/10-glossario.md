# Glossário

| Termo | Definição neste ecossistema |
|---|---|
| AI Workstation | Plataforma headless no computador; fonte do estado operacional, execução, políticas e integrações |
| RIN | Aplicativo Android e Control Plane da AI Workstation |
| Projeto Vivo | Primeiro módulo do RIN, dedicado à continuidade de projetos |
| AI Workstation Node/API | Serviço no Galaxy Book/PC; substitui o termo histórico “RIN Server” |
| Checkpoint | Registro estruturado do que foi feito, decidido, bloqueado e do próximo passo |
| Onde parei? | Resumo rastreável apresentado pelo Projeto Vivo |
| AI Shift | Handoff auditável entre agentes, solicitado/aprovado no RIN e executado pela plataforma |
| Hermes | Runtime de agentes candidato; ainda não adotado |
| Obsidian | Knowledge Hub candidato baseado em Markdown; opcional |
| Knowledge Hub | Conhecimento permanente, distinto de código e estado operacional |
| Provider | Serviço/modelo capaz de executar tarefas de IA |
| Approval Gate | Controle que exige decisão humana antes de ação crítica |
| Learning Gate | Propor, validar, aprovar e versionar aprendizados |
| Capability | Recurso que a plataforma declara suportar em sua versão/configuração atual |
| WorkstationGateway | Fronteira usada pelo RIN para consumir a API |
| Spike | Experimento curto para reduzir uma incerteza técnica |
| ADR | Registro de decisão arquitetural |
