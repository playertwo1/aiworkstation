# AI Workstation

Repositório de planejamento e, futuramente, implementação da plataforma pessoal de IA de Rafael.

O primeiro produto é o **Projeto Vivo**: um aplicativo Android que responde com clareza a quatro perguntas sobre cada projeto assistido por IA:

1. Onde parei?
2. O que mudou?
3. O que falta?
4. Qual é o próximo passo seguro?

O celular será o painel de controle. O Galaxy Book6 Pro será o nó de execução headless. GitHub será a fonte de verdade do código. Integrações com agentes, provedores e Obsidian serão adicionadas progressivamente, sempre atrás de interfaces substituíveis e gates de aprovação.

## Estado atual

**Fase 0 — documentação e descoberta.** Ainda não há código de produção. O foco é reduzir incertezas antes de escolher e acoplar infraestrutura.

## Regra de foco

Até o MVP provar valor, este repositório não implementará a plataforma bancária Diretor 360. A arquitetura poderá ser reaproveitada no futuro, mas o produto em construção agora é somente o Projeto Vivo.
