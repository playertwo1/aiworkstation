# Glossário

| Termo | Definição neste projeto |
|---|---|
| Projeto Vivo | Aplicativo/sistema pessoal de continuidade e orquestração de projetos assistidos por IA |
| AI Workstation | Repositório e visão mais ampla que contém o Projeto Vivo e futuras fundações compartilhadas |
| Control Plane | Interface Android usada para visualizar, decidir e autorizar |
| Execution Node | Galaxy Book executando serviços headless e tarefas autorizadas |
| Checkpoint | Registro estruturado do que foi feito, decidido, bloqueado e do próximo passo |
| Onde parei? | Resumo rastreável do estado atual do projeto |
| Hermes | Runtime de agentes candidato; ainda não adotado |
| Obsidian | Knowledge Hub candidato baseado em Markdown; opcional |
| Knowledge Hub | Repositório de conhecimento permanente, distinto de código e dados operacionais |
| Provider | Serviço/modelo capaz de executar tarefas de IA |
| Approval Gate | Controle que exige revisão humana antes de ação crítica |
| Learning Gate | Processo de propor, validar, aprovar e versionar novos aprendizados |
| Spike | Experimento curto destinado a reduzir uma incerteza técnica |
| ADR | Registro de decisão arquitetural |
